## Featured Projects

1️⃣ SpectraSoil: Soil Carbon & Health Analyzer

A research-driven platform for rapid estimation of soil carbon fractions and soil health indicators using near-infrared spectroscopy.

🔗 Live Application
https://spectroscopy-rapid-soil-carbon-ml.streamlit.app/

📂 Repository
https://github.com/SurajMelkani/Histosols-spectroscopy-soil-carbon-ml

Overview

SpectraSoil transforms near-infrared spectral signatures into actionable soil carbon and soil health metrics.

The platform is designed specifically for organic soils (Histosols) and enables rapid, non-destructive soil assessment for researchers, agronomists, and land managers.

Technical Note

The core machine learning and deep learning models were trained on more than 700 Everglades Agricultural Area Histosol samples.

Because this research is currently pending peer-reviewed publication, the public version operates in Demonstration Mode using a representative baseline model.

Research-grade trained models and calibration datasets are not included in the public repository and may be available upon request for academic collaboration.

2️⃣ Everglades Growers Decision Support System

An interactive spatial decision-support system predicting soil organic matter, subsidence risk, and management guidance based on field selection within the Everglades Agricultural Area.

🔗 Live Application
https://eaa-growers-dss.streamlit.app/

📂 Repository
https://github.com/SurajMelkani/Everglades-Growers-DSS

Context

This Decision Support System is a research tool developed within the Department of Soil, Water, and Ecosystem Sciences at the University of Florida. It functions as a digital interface for translating soil carbon and subsidence research into field-scale management decisions.

Model & Data Availability

The core predictive models were trained on more than 700 Histosol samples from the Everglades Agricultural Area.

The deployed public version currently operates using a representative baseline demonstration model. The fully calibrated model files and associated datasets are not included in this repository pending peer-reviewed publication.

Research-grade models and calibration datasets may be available upon request for academic collaboration, subject to publication timelines and data-sharing agreements.

Future Integration

Future versions are designed to integrate high-resolution earth observation data and multispectral imagery to refine spatial subsidence and soil health predictions.

3️⃣ Satellite & UAV Multispectral Vegetation Index Calculator

An interactive web-based tool built with Python and Streamlit to rapidly process and visualize multispectral imagery and RGB photos from satellite and drone platforms.

🔗 Live Application
https://satellite-uav-multispectral-vi-calculator.streamlit.app/

📂 Repository
https://github.com/SurajMelkani/Satellite-UAV-Multispectral-VI-Calculator

Overview

This application allows users to upload individual band GeoTIFFs (Red, Green, Near-Infrared, Red Edge, Blue) or RGB images to compute up to 11 vegetation indices.

Supported indices include:

NDVI, GNDVI, NDRE, SAVI

EVI, EVI2

RENDVI, NIRRENDVI

RGBVI, VARI

The tool processes imagery at preview resolution for rapid rendering and is designed for quick field assessments without requiring coordinate system transformations.

Sample datasets are included in the repository for testing.

Process-based carbon models:

Rothamsted Carbon Model

Century Model

Outputs
