# Suraj Melkani, PhD Candidate  
University of Florida – Soil, Water, and Ecosystem Sciences  

Welcome to my research portfolio. This GitHub serves as the software and modeling hub for my PhD research focused on:

- Soil Organic Carbon Dynamics  
- Digital Soil Mapping (EAA – Everglades Agricultural Area)  
- Soil Spectroscopy and Machine Learning  
- Precision Agriculture Decision Support Tools  

## Featured Projects

###1️⃣ SpectraSoil: Soil Carbon & Health Analyzer

A research-driven platform for rapid estimation of soil carbon fractions and soil health indicators using near-infrared spectroscopy.

[Launch Live SpectraSoil](https://spectroscopy-rapid-soil-carbon-ml.streamlit.app/)
[View GitHub Repository – SpectraSoil](https://github.com/SurajMelkani/Histosols-spectroscopy-soil-carbon-ml)

###2️⃣ Everglades Growers Decision Support System

An interactive spatial decision-support system predicting soil organic matter, subsidence risk, and management guidance based on field selection within the Everglades Agricultural Area.

[Launch Live Decision Support System](https://eaa-growers-dss.streamlit.app/)
[View GitHub Repository – Everglades Growers DSS](https://github.com/SurajMelkani/Everglades-Growers-DSS)

###3️⃣ Satellite & UAV Multispectral Vegetation Index Calculator

An interactive web-based tool built with Python and Streamlit to rapidly process and visualize multispectral imagery and RGB photos from satellite and drone platforms.

[Launch Live Satellite & UAV Multispectral Vegetation Index Calculator](https://satellite-uav-multispectral-vi-calculator.streamlit.app/)
[View GitHub Repository – Satellite & UAV Multispectral VI Calculator](https://github.com/SurajMelkani/Satellite-UAV-Multispectral-VI-Calculator)

###4️⃣ Soil Carbon Dynamics Simulator

An interactive simulation platform for comparing soil carbon model structures under consistent carbon input and initial stock scenarios.

[Launch Soil Carbon Dynamics Simulator](https://ljdrky-suraj-melkani.shinyapps.io/Soil_C_Simulation/)
[View GitHub Repository – Soil Carbon Dynamics Simulator](https://github.com/SurajMelkani/Soil-Carbon-Dynamics-Simulator-Model)


## Research Interests
Soil carbon stability, proximal sensing, machine learning pipelines, spatial modeling, and sustainable management of organic soils.
